Architecture

Five Memory Types. One Coherent Mind.

Other platforms dump everything into a vector store and call it memory. Nous runs five typed stores — each with distinct retrieval, decay modeling, and cross-type graph linking via spreading activation.

What Makes Nous Different

Built on Research. Shipped as Infrastructure.

Every major capability in Nous maps to a published finding in 2025–2026 LLM agent research — then ships as working code.

🔄 Memory as Policy

Every write — ADD, UPDATE, DELETE, NOOP — is a policy decision with a cost. The memory RL policy weighs expected future value before writing anything. Sparse rewards. No bloat.

🕸️ Spreading Activation

Recall isn't just vector similarity. Nous traverses a cross-type memory graph — surfacing related facts, decisions, and episodes the way human memory does: associatively, not literally.

📉 Memory Lifecycle

Memories decay, consolidate, and deduplicate automatically. Your agent doesn't accumulate noise — it curates. High-value memories strengthen. Low-value ones decay.

🧬 Auto-Evolving Skills

EvoSkill-inspired discovery loop: spawn executor subtasks, analyze failures, propose new skills, register them — all autonomously. The agent improves what it knows how to do.

🛡️ Prompt Injection Defense

Source-sink isolation architecture. Web content flows through sandboxed subtasks. Schema-validated output only. Memory writes require explicit authorization — never silently triggered by external content.

📊 Decision Intelligence

Not just what your agent did — but why. Confidence scores, reasoning traces, and calibration tracking over time. When it's wrong, it records that too. Trust earned, not assumed.
