in production setups; tracked locally for traceability).

## Workflow — after every eval run

This is the discipline that prevents lost stats:

1. **Eval CLI writes the report** to `reports/<descriptive-name>/`.
2. **Open the report, copy:** date, git_sha, configs, headline metrics.
3. **Append one row to [RUNS.md](RUNS.md)** with the result + decision
   (or `exploratory` if no decision yet).
4. If the run **closes a work item** in
   [EXECUTION-PLAN.md](EXECUTION-PLAN.md), add a `**done:** <link>`
   line under that item.
5. If the run is a **session-level deliverable** (multiple coordinated
   runs forming a story), also write a session doc
   `evaluations/YYYY-MM-DD-<topic>.md` and add a row under "Sessions".

For F051 retrieval runs, the auto-recorded entry in
`nous_system.eval_runs` is the source-of-truth for the harness, but
the human-readable RUNS.md row is what makes findings discoverable.

## Eval framework reference

- **Harness:** `nous_eval/` package
- **CLI:** `python -m nous_eval.retrieval --configs <name1>,<name2> --sources <src1>`
- **Configs:** declared in `nous_eval/retrieval.py::_DEFAULT_CONFIGS`
- **Eval DB:** Docker container `nous-eval-scratch` on `127.0.0.1:5433`
- **Agents available:** `nous-prod-snapshot` (codebase, 2027 facts), `nous-lme-corpus` (personal-Q&A, 933 facts + 200 episodes)
- **Qrel sources:** `tests/fixtures/qrels_nous_prod.jsonl` (40q), `tests/fixtures/qrels_nous_prod_procedures.jsonl` (50q), `tests/fixtures/qrels_longmemeval.jsonl` (20q)

### Running the harness locally

```bash
# Codebase corpus
NOUS_EVAL_DB_NAME=nous_eval_scratch \
NOUS_EVAL_AGENT_ID=nous-prod-snapshot \
uv run python -m nous_eval.retrieval \
  --configs baseline,ce_off \
  --sources nous_prod,nous_prod_procedures \
  --include-unreviewed --no-history \
  --report-dir reports/myrun

# Personal-Q&A corpus
NOUS_EVAL_DB_NAME=nous_eval_scratch \
NOUS_EVAL_AGENT_ID=nous-lme-corpus \
NOUS_EVAL_FIXTURES_DIR=tests/fixtures \
uv run python -m nous_eval.retrieval \
  --configs baseline,ce_off \
  --sources longmemeval \
  --include-unreviewed --no-history \
  --report-dir reports/myrun_lme
```
